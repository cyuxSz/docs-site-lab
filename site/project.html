¿Cómo se actualiza?

  1. Se edita openwiki/ en el repo del proyecto (a mano o con /actualizar-docs), o se agrega un HTML de Archify en docs/arch/.
  2. El CI wiki-claims confirma que las citas siguen apuntando al código.
  3. Con el merge a main, el repo avisa al portal y este se reconstruye.
